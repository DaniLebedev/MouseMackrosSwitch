# MouseMackros

Контекстные раскладки для мыши **MBF1000PRO**: приложение смотрит, какое окно сейчас активно, и превращает дополнительные кнопки мыши в нужные действия — навигацию в браузере, игровые клавиши в игре, управление музыкой в плеере.

Фирменная программа мыши не умеет переключать профили по активному окну. MouseMackros делает это сам: глобально перехватывает ввод и выполняет действия из профиля, привязанного к текущему процессу.

```
Кнопка мыши → MBF1000PRO шлёт Ctrl+Alt+Shift+A → MouseMackros ловит сочетание
             → смотрит активное окно → выполняет действие из нужного профиля
```

---

## Возможности

- Два столбца: слева профили приложений, справа — кнопки мыши с номерами и действиями из `.psf`.
- Действия кнопок **читаются из `.psf`** фирменной программы: ничего не нужно назначать вручную.
- К одной профильной записи можно привязать **несколько приложений** (например, Chrome, Firefox и Edge).
- Неназначенные в `.psf` кнопки не показываются; подписи к действиям можно менять для себя.
- Автоматический выбор профиля по процессу, заголовку и классу окна (шаблоны `*`, `?`, приоритеты).
- Поддержка действий из `.psf`: сочетания клавиш, макросы, боковые кнопки Forward/Backward; спец-клавиши вроде Fire Key блокируются.
- Работа в трее, пауза по `Ctrl+Alt+P`, автозапуск с Windows, импорт/экспорт профилей в JSON.
- Тёмная тема, меню **Файл / Профиль / Изменить / Справка**, окно диагностики ввода.

## Быстрый старт

1. Запустите `MouseMackros.exe`. Приложение откроется и останется в трее; закрытие окна не выключает его.
2. Меню **Файл → Создать профиль для мыши (.psf)…**. Файл `MouseMackros.psf` появится в `data\psf\` (в репозитории) или в `%APPDATA%\MouseMackros\psf\` (для обычной сборки). Каждая редактируемая кнопка будет отправлять `Ctrl+Alt+Shift+A…M`.
3. Откройте **MBF1000PRO Mouse** → **Config** → импорт профиля → выберите `MouseMackros.psf`, нажмите «Применить», затем **выберите профиль MouseMackros в списке** — он должен стать активным. **Этот профиль должен быть активен на мыши постоянно.**
4. В MouseMackros создайте профиль (**«＋»**), добавьте приложение и загрузите его `.psf` (например, `firefox.psf`). Действия кнопок подтянутся автоматически.
5. Повторите для остальных приложений. Профиль включается сам, когда активно окно любого из его приложений.

> Почему нужен отдельный `MouseMackros.psf`: фирменная программа умеет хранить только одну активную раскладку. Если оставить `word.psf`, кнопка 3 всегда шлёт `Ctrl+C` — и в Word, и в Firefox. С нейтральной раскладкой кнопка 3 шлёт свою комбинацию, а MouseMackros уже решает, что сделать в активном окне.

### Куда сохраняются данные

В репозитории данные лежат рядом с решением, в папке `data`:

```
data\
  settings.json          общие настройки (пауза, уведомления, автозапуск)
  profiles\<id>.json     по одному файлу на профиль
  psf\                   сгенерированные раскладки .psf
  log.txt                ошибки (не коммитится)
```

Папка `data` **попадает в git**, поэтому профили и сгенерированный `MouseMackros.psf` сохраняются при клонировании. `log.txt` исключён через `.gitignore`.

Если приложение запущено вне репозитория (опубликованная сборка), используется `%APPDATA%\MouseMackros`, а если рядом с `.exe` уже есть папка `data` — она. Путь можно задать вручную: `MouseMackros.exe --data-dir D:\MyProfiles`; этот же механизм используют e2e-тесты.

При первом запуске portable-версии старые данные из `%APPDATA%\MouseMackros` автоматически копируются в `data`. Совсем старый `config.json` мигрирует в новое хранилище и архивируется как `config.json.migrated`.

## Как работают профили

Профиль привязывается к приложениям через **«Добавить приложение…»**: в правило попадает имя процесса. Приложений может быть сколько угодно — например, один профиль «Браузеры» для Chrome, Firefox и Edge. Для тонкой настройки откройте **«Правила…»**:

| Поле | Что означает | Пример |
|---|---|---|
| Программы | Имена процессов без `.exe`, через запятую; `*` и `?` — шаблоны | `chrome, msedge, *game*` |
| Заголовок содержит | Подстрока заголовка активного окна | `YouTube` |
| Класс окна | Точное имя класса окна | `Chrome_WidgetWin_1` |
| Приоритет | Чем больше, тем важнее при совпадении нескольких профилей | `20` |

Если ни один профиль не подошёл, работает **резервный профиль** («Везде (по умолчанию)»). Сделать профиль основным можно в меню **Профиль → Сделать основным**.

### Загрузка действий из .psf

Кнопка **«Раскладка .psf…»** читает файл фирменной программы и создаёт действия для всех назначенных в нём кнопок. Triggers при этом остаются нейтральными (`Ctrl+Alt+Shift+…`), поэтому одна и та же кнопка работает по-разному в каждом профиле.

Поддерживаются:

- сочетания клавиш (`Copy` = `Ctrl+C`, `Paste` = `Ctrl+V`);
- макросы MBF1000PRO (например, переключение вкладок);
- Forward / Backward (боковые кнопки `X1/X2`);
- запуск программ и ссылок, заданных в `.psf` (кнопка `KeyNURL`);
- спец-действия вроде Fire Key показываются, но блокируются — их нельзя воспроизвести.

Подпись у кнопки можно изменить кнопкой **«Подпись…»** — это только пометка в интерфейсе.

Если на мыши активна другая раскладка (например, `word.psf`), в карточке профиля появляется предупреждение **«На мыши профиль …»** с кнопкой **«исправить»**: приложение читает `CurrentProfile` из конфигурации MBF1000PRO и проверяет, что кнопки 1–3 шлют нейтральные сочетания.

## Действия

Действия берутся из `.psf`; вручную они не назначаются. Внутри приложения поддерживаются:

| Тип | Пример | Комментарий |
|---|---|---|
| Клавиши | `Ctrl+Shift+T` | Одно нажатие сочетания |
| Текст | `Привет` | Печатает текст посимвольно (Unicode) |
| Медиа | `PlayPause`, `Next`, `VolumeUp` | Медиа-клавиши Windows |
| Макрос | см. ниже | Несколько шагов подряд |
| Запуск | `notepad.exe` + аргументы | Программа, файл или URL |
| Прокрутка | `1` / `-3` | Положительное значение — вверх |
| Профиль | `games` | Переключает профиль до смены окна |

### Язык макросов

Одна команда на строку, `#` — комментарий:

```
# рывок
press Space
delay 60
press Shift
down Ctrl
press A
up Ctrl
wheel down 2
text gg
press mouse:left
```

| Команда | Назначение |
|---|---|
| `press Ctrl+A` | Нажать сочетание |
| `down Shift` / `up Shift` | Зажать / отпустить клавишу или модификатор |
| `delay 150` | Пауза, миллисекунды |
| `text hello` | Напечатать текст (кириллица поддерживается) |
| `wheel up 3` | Прокрутка: `up`, `down`, `left`, `right` |
| `press mouse:left` | Клик мышью: `left`, `right`, `middle`, `x1`, `x2` |

Режимы: **однократно**, **удержание** (повтор, пока кнопка зажата), **переключение** (первое нажатие запускает, второе останавливает). Поле «Повторы» задаёт количество дополнительных проигрываний.

## Ограничения

- Игры, читающие ввод через Raw Input, могут увидеть служебные сочетания `Ctrl+Alt+Shift+…`. Обычно они безвредны; MouseMackros перехватывает их первым.
- Спец-действия MBF1000PRO (Fire Key, смена DPI и т. п.) не воспроизводятся — такая кнопка блокируется.
- Античиты могут блокировать синтетический ввод (`SendInput`). Используйте приложение там, где это разрешено правилами игры.
- Действия не попадут в окно программы, запущенной от имени администратора, если MouseMackros запущен без прав администратора.
- Фирменное ПО MBF1000PRO может перезаписывать свои профили при сохранении. Импортированный профиль не редактируйте в нём — при необходимости создайте заново.
- Приложение работает только в текущей сессии пользователя и не является службой.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```powershell
git clone <репозиторий>
cd MouseMackrosSwitch
dotnet build MouseMackros.slnx
```

Готовый файл: `src\MouseMackros\bin\Debug\net10.0-windows\MouseMackros.exe`.

Публикация (зависит от установленного .NET 10 Desktop Runtime):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained false -o publish
```

Автономная сборка одним файлом (Runtime не нужен, размер больше):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

### Тесты

```powershell
dotnet run --project tests\MouseMackros.SelfTest
powershell -ExecutionPolicy Bypass -File tests\e2e.ps1
```

`SelfTest` проверяет пресеты, JSON, шаблоны, разбор клавиш, макросы, карту кнопок, чтение `.psf` (включая макросы вкладок и Copy/Paste), перенос действий в профиль и хранилище. `e2e.ps1` запускает приложение с временной папкой `--data-dir`, эмулирует `Ctrl+Alt+Shift+F12` и боковую кнопку `X1`, проверяет срабатывание действий и удаляет временные данные.

## Структура проекта

```
src/MouseMackros/
  Engine/        обработка ввода, выбор профиля, выполнение действий и макросов
  Input/         глобальные хуки клавиатуры и мыши, модель триггеров
  Interop/       Win32 P/Invoke, отправка ввода, имена клавиш
  Model/         профили, правила, привязки, действия
  Services/      хранилище профилей, пресеты, .psf, каталог приложений, автозапуск
  MainWindow.*   два столбца: профили и кнопки
  AppPickerDialog.*   выбор приложения
  SettingsWindow.*    общие настройки
  RulesDialog.*       правила срабатывания
  AnnotationDialog.*  подписи к кнопкам
tests/
  MouseMackros.SelfTest/   консольные проверки
  e2e.ps1                  сквозной тест через реальные хуки
data/                      профили, настройки и .psf (коммитится в git)
```
