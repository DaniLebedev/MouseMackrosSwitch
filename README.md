# MouseMackros

Контекстные раскладки для мыши **MBF1000PRO**: приложение смотрит, какое окно сейчас активно, и превращает дополнительные кнопки мыши в нужные действия — навигацию в браузере, игровые клавиши в игре, управление музыкой в плеере.

Фирменная программа мыши не умеет переключать профили по активному окну. MouseMackros делает это сам: глобально перехватывает ввод и выполняет действия из профиля, привязанного к текущему процессу.

```
Кнопка мыши → MBF1000PRO шлёт Ctrl+Alt+Shift+A → MouseMackros ловит сочетание
             → смотрит активное окно → выполняет действие из нужного профиля
```

---

## Возможности

- Профили с автоматическим выбором по процессу, заголовку окна и классу окна (поддерживаются шаблоны `*`, `?`).
- Приоритеты: если подходит несколько профилей, побеждает профиль с большим приоритетом.
- Действия: сочетания клавиш, текст, медиа-клавиши, запуск программ, прокрутка, переключение профиля, макросы.
- Режимы макросов: один раз, удержание, переключение; счётчик повторов.
- Захват любой кнопки или сочетания («Захват ввода») — можно назначить не только `Ctrl+Alt+Shift+A…M`, но и боковые кнопки `X1/X2`, колесо и любые клавиши.
- Готовый профиль для MBF1000PRO: каждая дополнительная кнопка начинает отправлять своё сочетание.
- Работа в трее, пауза по `Ctrl+Alt+P`, автозапуск с Windows, импорт/экспорт настроек в JSON.

## Быстрый старт

1. Запустите `MouseMackros.exe`. Приложение откроется и останется в трее; закрытие окна не выключает его.
2. Нажмите **«Профиль для MBF1000PRO…»**. В папке профилей фирменной программы появится `MouseMackros.psf`, а кнопки 4–16 будут отправлять `Ctrl+Alt+Shift+A`, `…+B`, … `…+M`.
3. Откройте **MBF1000PRO Mouse** → **Config** → импорт профиля → выберите `MouseMackros.psf` и примените его к мыши.
4. Вернитесь в MouseMackros. В профиле **«Браузер»** сочетания `Ctrl+Alt+Shift+A…M` уже назначены на вкладки, историю, обновление и т. п. В профиле **«Игры»** — на цифры и игровые клавиши. Настройте под себя.
5. Для игрового профиля заполните правило: например, процессы `cs2, dota2, *game*`. Без правил профиль не включается автоматически.

> Профиль MBF1000PRO создаётся из шаблона `default0.psf`. Если фирменная программа перезапишет профили при выходе, просто создайте `MouseMackros.psf` заново и импортируйте его.

### Куда сохраняются настройки

`%APPDATA%\MouseMackros\config.json` — профили и правила. Кнопка **«Папка с настройками»** открывает её. Там же лежит `log.txt` с ошибками. Кнопки импорта и экспорта JSON находятся над списком профилей.

## Как работают профили

У профиля есть правило «Когда включать»:

| Поле | Что означает | Пример |
|---|---|---|
| Программы | Имена процессов без `.exe`, через запятую; `*` и `?` — шаблоны | `chrome, msedge, *game*` |
| Заголовок содержит | Подстрока заголовка активного окна | `YouTube` |
| Класс окна | Точное имя класса окна | `Chrome_WidgetWin_1` |
| Приоритет | Чем больше, тем важнее при совпадении нескольких профилей | `20` |

Если ни один профиль не подошёл, работает **резервный профиль** («Везде (по умолчанию)»). Кнопка **«+ активное окно»** добавляет имя процесса текущего окна в поле «Программы».

Кнопка **«Захват ввода»** включает режим обучения: нажмите любую клавишу, сочетание или кнопку мыши — она станет триггером новой привязки. Во время захвата ввод не доходит до других программ.

## Действия

| Тип | Пример | Комментарий |
|---|---|---|
| Клавиши | `Ctrl+Shift+T` | Одно нажатие сочетания |
| Текст | `Привет` | Печатает текст посимвольно (Unicode) |
| Медиа | `PlayPause`, `Next`, `VolumeUp` | Медиа-клавиши Windows |
| Макрос | см. ниже | Несколько шагов подряд |
| Запуск | `notepad.exe` + аргументы | Программа, файл или URL |
| Прокрутка | `1` / `-3` | Положительное значение — вверх |
| Профиль | `games` | Переключает профиль до смены окна |

Триггеры: сочетания клавиш (`Ctrl+Alt+Shift+A`), боковые кнопки (`mouse:X1`, `mouse:X2`), наклон/прокрутка колеса (`wheel:Up`, `wheel:Down`, `wheel:Left`, `wheel:Right`).

### Язык макросов

Одна команда на строку, `#` — комментарий:

```
# рывок
press Space
delay 60
press Shift
down Ctrl
press A
up Ctrl
wheel down 2
text gg
press mouse:left
```

| Команда | Назначение |
|---|---|
| `press Ctrl+A` | Нажать сочетание |
| `down Shift` / `up Shift` | Зажать / отпустить клавишу или модификатор |
| `delay 150` | Пауза, миллисекунды |
| `text hello` | Напечатать текст (кириллица поддерживается) |
| `wheel up 3` | Прокрутка: `up`, `down`, `left`, `right` |
| `press mouse:left` | Клик мышью: `left`, `right`, `middle`, `x1`, `x2` |

Режимы: **однократно**, **удержание** (повтор, пока кнопка зажата), **переключение** (первое нажатие запускает, второе останавливает). Поле «Повторы» задаёт количество дополнительных проигрываний.

## Ограничения

- Игры, читающие ввод через Raw Input, могут увидеть служебные сочетания `Ctrl+Alt+Shift+…`. Обычно они безвредны; если мешают — назначьте на кнопки другие клавиши через «Захват ввода» или используйте оконный режим.
- Античиты могут блокировать синтетический ввод (`SendInput`). Используйте приложение там, где это разрешено правилами игры.
- Действия не попадут в окно программы, запущенной от имени администратора, если MouseMackros запущен без прав администратора. Запустите его от администратора в таком случае.
- Фирменное ПО MBF1000PRO может перезаписывать свои профили при сохранении. Импортированный профиль не редактируйте в нём — при необходимости создайте заново.
- Приложение работает только в текущей сессии пользователя и не является службой.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```powershell
git clone <репозиторий>
cd MouseMackrosSwitch
dotnet build MouseMackros.slnx
```

Готовый файл: `src\MouseMackros\bin\Debug\net10.0-windows\MouseMackros.exe`.

Публикация (зависит от установленного .NET 10 Desktop Runtime):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained false -o publish
```

Автономная сборка одним файлом (Runtime не нужен, размер больше):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

### Тесты

```powershell
dotnet run --project tests\MouseMackros.SelfTest
powershell -ExecutionPolicy Bypass -File tests\e2e.ps1
```

`SelfTest` проверяет пресеты, JSON, шаблоны, разбор клавиш, макросы и генерацию `.psf`. `e2e.ps1` подменяет конфиг на время проверки, запускает приложение, эмулирует `Ctrl+Alt+F12` и боковую кнопку `X1`, проверяет срабатывание действий и восстанавливает исходный конфиг.

## Структура проекта

```
src/MouseMackros/
  Engine/        обработка ввода, выбор профиля, выполнение действий и макросов
  Input/         глобальные хуки клавиатуры и мыши, модель триггеров
  Interop/       Win32 P/Invoke, отправка ввода, имена клавиш
  Model/         профили, правила, привязки, действия
  Services/      конфиг, пресеты, генератор профиля MBF1000PRO, автозапуск
  MainWindow.*   редактор профилей
tests/
  MouseMackros.SelfTest/   консольные проверки
  e2e.ps1                  сквозной тест через реальные хуки
```
