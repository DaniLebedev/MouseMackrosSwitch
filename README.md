# MouseMackros

Контекстные раскладки для мыши **MBF1000PRO**: приложение смотрит, какое окно сейчас активно, и превращает дополнительные кнопки мыши в нужные действия — навигацию в браузере, игровые клавиши в игре, управление музыкой в плеере.

Фирменная программа мыши не умеет переключать профили по активному окну. MouseMackros делает это сам: глобально перехватывает ввод и выполняет действия из профиля, привязанного к текущему процессу.

```
Кнопка мыши → MBF1000PRO шлёт Ctrl+Alt+Shift+A → MouseMackros ловит сочетание
             → смотрит активное окно → выполняет действие из нужного профиля
```

---

## Возможности

- Два столбца: слева профили приложений, справа — кнопки мыши с номерами и действиями из `.psf`.
- Действия кнопок **читаются из `.psf`** фирменной программы: ничего не нужно назначать вручную.
- К одной профильной записи можно привязать **несколько приложений** (например, Chrome, Firefox и Edge).
- Неназначенные в `.psf` кнопки не показываются; подписи к действиям можно менять для себя.
- Показываются только физические кнопки мыши. Колесо и клавиатурные сочетания не перехватываются — их раскладка остаётся в фирменном софте мыши.
- **Ручные подраскладки** внутри профиля (до 6 слоёв), переключение кнопками мыши и цвет колеса как индикатор профиля/слоя.
- Автоматический выбор профиля по процессу, заголовку, классу окна и URL (шаблоны `*`, `?`, приоритеты).
- Поддержка действий из `.psf`: сочетания клавиш, макросы, боковые кнопки Forward/Backward; спец-клавиши вроде Fire Key блокируются.
- Макросы для браузера: страницы `?page=`, параметры URL, сегменты пути, вкладки, история, поиск, масштаб, копирование адреса.
- Системные макросы: буфер обмена, запуск программ, окна, громкость, медиа, скриншот, блокировка, сон, профили и слои.
- Блоки `repeat`, `while`, `if/else`, переменные, выражения и подстановки `{clipboard}`, `{date}`, `{url}`, `{param:...}`.
- Настройка скорости набора: общая, для профиля и для отдельной команды (`text "…" 100`, `-1` — мгновенно).
- Загрузка макросов из файлов `.macro`, сохранение и открытие в VS Code; расширение с подсветкой, автодополнением и проверкой синтаксиса.
- Работа в трее, пауза по `Ctrl+Alt+P`, автозапуск с Windows, импорт/экспорт профилей в JSON.
- Тёмная тема, меню **Файл / Профиль / Изменить / Справка**, окно диагностики ввода.

## Быстрый старт

1. Запустите `MouseMackros.exe`. Приложение откроется и останется в трее; закрытие окна не выключает его.
2. Меню **Файл → Создать профиль для мыши (.psf)…**. Файл `MouseMackros.psf` появится в `data\psf\` (в репозитории) или в `%APPDATA%\MouseMackros\psf\` (для обычной сборки). Каждая редактируемая кнопка будет отправлять `Ctrl+Alt+Shift+A…M`.
3. Откройте **MBF1000PRO Mouse** → **Config** → выберите профиль, который будет активным (подсвечен красным) → **правый клик по нему → Import** → `MouseMackros.psf`. После импорта в Key Assignment должно быть `MM:A`…`MM:M`. **Именно этот профиль должен быть активен на мыши постоянно.**
4. В MouseMackros создайте профиль (**«＋»**), добавьте приложение и загрузите его `.psf` (например, `firefox.psf`). Действия кнопок подтянутся автоматически.
5. Повторите для остальных приложений. Профиль включается сам, когда активно окно любого из его приложений.

> Почему нужен отдельный `MouseMackros.psf`: фирменная программа умеет хранить только одну активную раскладку. Если оставить `word.psf`, кнопка 3 всегда шлёт `Ctrl+C` — и в Word, и в Firefox. С нейтральной раскладкой кнопка 3 шлёт свою комбинацию, а MouseMackros уже решает, что сделать в активном окне.

### Куда сохраняются данные

В репозитории данные лежат рядом с решением, в папке `data`:

```
data\
  settings.json          общие настройки (пауза, уведомления, автозапуск)
  profiles\<id>.json     по одному файлу на профиль
  psf\                   сгенерированные раскладки .psf
  macros\                файлы макросов .macro для загрузки и VS Code
  log.txt                ошибки (не коммитится)
```

Папка `data` **попадает в git**, поэтому профили и сгенерированный `MouseMackros.psf` сохраняются при клонировании. `log.txt` исключён через `.gitignore`.

Если приложение запущено вне репозитория (опубликованная сборка), используется `%APPDATA%\MouseMackros`, а если рядом с `.exe` уже есть папка `data` — она. Путь можно задать вручную: `MouseMackros.exe --data-dir D:\MyProfiles`; этот же механизм используют e2e-тесты.

При первом запуске portable-версии старые данные из `%APPDATA%\MouseMackros` автоматически копируются в `data`. Совсем старый `config.json` мигрирует в новое хранилище и архивируется как `config.json.migrated`.

## Как работают профили

Профиль привязывается к приложениям через **«Добавить приложение…»**: в правило попадает имя процесса. Приложений может быть сколько угодно — например, один профиль «Браузеры» для Chrome, Firefox и Edge. Для тонкой настройки откройте **«Правила…»**:

| Поле | Что означает | Пример |
|---|---|---|
| Программы | Имена процессов без `.exe`, через запятую; `*` и `?` — шаблоны | `chrome, msedge, *game*` |
| Условие | Мини-язык: URL, заголовок, процесс, класс окна | `browser.url contains "nexusmods.com"` |
| Приоритет | Чем больше, тем важнее при совпадении нескольких профилей | `20` |

«Заголовок содержит» и «Класс окна» остались для старых профилей, но спрятаны под чекбоксом **«Дополнительные фильтры»**. Для новых правил достаточно условия: `title contains "…"` и `class == "…"` делают то же самое. Кнопка **«Подсказки»** открывает отдельное окно с примерами и операторами.

Если ни один профиль не подошёл, работает **резервный профиль** («Везде (по умолчанию)»). Сделать профиль основным можно в меню **Профиль → Сделать основным**.

### Подпрофили: сайты, документы, игры

У профиля могут быть **вложенные подпрофили**. Условие задаётся мини-языком и проверяется вместе с правилами родителя:

```
browser.url contains "youtube.com"
title contains "YouTube"
process == "firefox" && browser.url startsWith "https://"
```

Поля: `browser.url`/`url`, `title`, `process`/`app`, `class`.
Операторы: `==`, `!=`, `contains`, `startsWith`, `endsWith`, `~=` (regex), `!`, `&&`, `||`, скобки. `==` понимает шаблоны `*` и `?`.

1. Выберите родительский профиль, например **«Браузер»**.
2. Откройте нужный сайт (или документ) и вернитесь в MouseMackros.
3. Меню **Профиль → Подпрофиль для текущего окна…** — условие подставится из URL или заголовка.
4. Для точной настройки откройте **«Правила…»** и впишите своё условие.

URL читается из адресной строки Firefox и Chromium-браузеров через UI Automation. Firefox показывает адрес без схемы (`www.nexusmods.com/...`), поэтому MouseMackros добавляет `https://` сам — условия вида `browser.url contains "https://www.nexusmods.com"` работают. Если браузер не отдаёт адресную строку, используйте `title`. URL и заголовок участвуют в определении профиля, поэтому переключение вкладок и переходы внутри сайта пересчитывают подпрофиль.

Подпрофиль показывается в списке с отступом, имеет приоритет над родителем, а при удалении родителя удаляется вместе с ним.

### Ручные подраскладки и цвет колеса

Внутри профиля можно сделать до **6 ручных слоёв** — например, для игры, где не хватает кнопок:

1. **Профиль → Ручные раскладки…**
2. **Добавить** слой и загрузить в него свой `.psf`.
3. Выбрать кнопки **«следующий слой»** и **«предыдущий слой»**. Одна кнопка листает по кругу вперёд; две — вперёд и назад. Базовый профиль тоже входит в цикл.
4. Задать цвет профиля и цвет каждого слоя.

Колесо/индикатор DPI используется как индикатор: MouseMackros отправляет цвет через HID (`06 03`) при смене профиля или слоя. Цвет слоя имеет приоритет над цветом профиля; пустой цвет означает «не менять». Для записи цвета закройте MBF1000PRO, иначе он может перехватить/перезаписать настройку.

Цвет колеса задаётся **рядом с именем профиля** кнопкой «цвет колеса» — не нужно открывать ручные раскладки. Тот же цвет показывается точкой в списке профилей. Цвет профиля, подпрофиля и ручного слоя — это один и тот же `IndicatorColor`, поэтому он всегда совпадает с цветом колеса.

Управляющие кнопки работают во всём профиле и имеют приоритет над действиями слоя. Цвет хранится в профиле (`IndicatorColor`) и в слое; слои — это дочерние профили с `IsManualLayer`.

В списке кнопок доступны и основные кнопки мыши: **12 — ЛКМ, 13 — ПКМ, 14 — СКМ**. Если назначить их на слой, обычный клик/перетаскивание/прицеливание в этом профиле перехватывается. Колёсико (14) — самый безопасный вариант; ЛКМ/ПКМ используйте только осознанно.

### Загрузка действий из .psf

Кнопка **«Раскладка .psf…»** читает файл фирменной программы и создаёт действия для всех назначенных в нём кнопок. Triggers при этом остаются нейтральными (`Ctrl+Alt+Shift+…`), поэтому одна и та же кнопка работает по-разному в каждом профиле.

Поддерживаются:

- сочетания клавиш (`Copy` = `Ctrl+C`, `Paste` = `Ctrl+V`);
- макросы MBF1000PRO (например, переключение вкладок);
- Forward / Backward (боковые кнопки `X1/X2`);
- запуск программ и ссылок, заданных в `.psf` (кнопка `KeyNURL`);
- спец-действия вроде Fire Key показываются, но блокируются — их нельзя воспроизвести.

Подпись у кнопки можно изменить кнопкой **«Подпись…»** — это только пометка в интерфейсе.

Если на мыши активна другая раскладка (например, `word.psf`), в карточке профиля появляется предупреждение **«На мыши профиль …»** с кнопкой **«исправить»**: приложение читает `CurrentProfile` из конфигурации MBF1000PRO и проверяет, что кнопки 1–3 шлют нейтральные сочетания.

## Действия

Действия берутся из `.psf`, но для любой кнопки можно открыть **«Макрос…»** и задать своё действие вручную (оно перекрывает `.psf`). Внутри приложения поддерживаются:

| Тип | Пример | Комментарий |
|---|---|---|
| Клавиши | `Ctrl+Shift+T` | Одно нажатие сочетания |
| Текст | `Привет` | Печатает текст посимвольно (Unicode) |
| Медиа | `PlayPause`, `Next`, `VolumeUp` | Медиа-клавиши Windows |
| Макрос | см. ниже | Несколько шагов подряд |
| Запуск | `notepad.exe` + аргументы | Программа, файл или URL |
| Прокрутка | `1` / `-3` | Положительное значение — вверх |
| Профиль | `games` | Переключает профиль до смены окна |

### Язык макросов

Одна команда на строку, `#` — комментарий:

```
# рывок
press Space
delay 60
press Shift
down Ctrl
press A
up Ctrl
wheel down 2
text gg
press mouse:left
```

| Команда | Назначение |
|---|---|
| `press Ctrl+A` | Нажать сочетание |
| `down Shift` / `up Shift` | Зажать / отпустить клавишу или модификатор |
| `delay 150` | Пауза, миллисекунды |
| `text hello` | Напечатать текст (кириллица поддерживается) |
| `text "hello" 100` | Текст с задержкой 100 мс между символами |
| `text "hello" -1` | Текст мгновенно |
| `wheel up 3` | Прокрутка: `up`, `down`, `left`, `right` |
| `press mouse:left` | Клик мышью: `left`, `right`, `middle`, `x1`, `x2` |
| `move 10 -5` | Сдвинуть курсор на x/y пикселей |
| `cursor right 10` | Сдвинуть курсор: `left`, `right`, `up`, `down` |
| `browser page +1` / `-1` | Следующая/предыдущая страница по параметру `page=` в URL |
| `browser page 287` | Перейти на конкретную страницу |
| `browser set_param "page" "287"` | Задать параметр URL (число или строка) |
| `browser change_param "page" +1` | Изменить числовой параметр URL |
| `browser set_param_url 2 "999"` | Заменить 2-й сегмент пути |
| `browser change_param_url 2 +1` | Изменить числовой сегмент пути |
| `browser tab new "https://…" 2` | Новая вкладка на позиции 2 |
| `browser tab new "https://…" 2 background` | Новая вкладка в фоне |
| `browser tab close 2` | Закрыть 2-ю вкладку |
| `browser tab next` / `prev` / `reopen` | Следующая / предыдущая / вернуть закрытую |
| `browser select 3` | Перейти на вкладку 3 |
| `browser open_in_new_tab ["https://…"]` | Открыть URL (или текущую страницу) в новой вкладке |
| `browser back` / `forward` / `stop` | Назад / вперёд / остановить загрузку |
| `browser update` / `browser reload hard` | Обновить / обновить без кэша |
| `browser zoom +1` / `-1` / `reset` | Масштаб страницы |
| `browser find "текст"` | Поиск на странице (`Ctrl+F`) |
| `browser search "запрос"` | Поиск через адресную строку |
| `browser copy_url` | Скопировать текущий адрес |
| `browser scroll top` / `bottom` | В начало / конец страницы |
| `browser goto "https://…"` | Открыть URL в активном браузере |
| `clipboard set "текст"` / `paste` / `clear` | Буфер обмена |
| `run "notepad.exe"` | Запустить программу |
| `open "D:\folder"` | Открыть файл, папку или ссылку |
| `window activate "Заголовок"` | Переключиться на окно |
| `window minimize` / `maximize` / `restore` / `close` | Действие с активным окном |
| `volume +5` / `-5`, `mute` | Громкость |
| `media next` / `prev` / `play` | Медиа-клавиши |
| `screenshot` / `lock` / `sleep` | Ножницы Windows / блокировка / сон |
| `profile next` / `prev` / `set games` | Переключить профиль |
| `layer next` / `prev` / `set 2` | Переключить ручной слой |
| `text {clipboard} {date} {time} {url} {param:page}` | Подстановки в тексте |
| `set counter = 5` / `let name = "nexus"` | Задать переменную |
| `inc counter` / `dec counter 2` | Увеличить / уменьшить переменную |
| `text {counter}` | Подставить переменную |
| `repeat 5 { ... }` | Повторить блок |
| `while counter < 10 { ... }` | Повторять, пока условие верно |
| `if browser.url contains "nexus" { ... } else { ... }` | Условие |

`browser` читает URL из адресной строки Firefox/Chromium и переходит через `Ctrl+L` + ввод адреса + `Enter`. Браузер должен быть активным окном. Если в URL нет `page=`, `page +1` сообщит об ошибке, а `page 287` добавит параметр.

Параметры запроса: `set_param` заменяет `?name=value` или `&name=value`; если параметра нет, он добавляется. `change_param` работает только с числом и не меняет остальные параметры. Имя параметра можно не заключать в кавычки, если в нём нет пробелов; значение лучше всегда писать в кавычках.

Сегменты пути нумеруются с 1:

```
https://steamcommunity.com/app/1366540
                              ^ 1  ^ 2
browser change_param_url 2 +1   → …/app/1366541
browser set_param_url 2 "730"   → …/app/730
```

`tab new` вставляет вкладку после указанной позиции: `2` — новая вкладка станет второй. Позицию `1` браузеры не позволяют вставить клавиатурой, поэтому она обрабатывается как обычный `Ctrl+T`. `tab new ... background` открывает вкладку и возвращает фокус на прежнюю. `tab close` без номера закрывает активную вкладку. Номера вкладок ограничены клавишами `Ctrl+1…Ctrl+8`; `Ctrl+9` всегда выбирает последнюю вкладку.

`browser open_in_new_tab` без аргумента дублирует текущую страницу в новой вкладке; с аргументом открывает указанный URL.

### Скорость набора

Скорость задаётся задержкой между символами в миллисекундах:

- `-1` — мгновенно, без задержки (текст отправляется крупными пакетами);
- `0` — без паузы, посимвольно;
- `3` — быстро (значение по умолчанию);
- больше — медленнее.

Три уровня настройки:

1. **Настройки → НАБОР ТЕКСТА** — общая скорость для всех профилей.
2. Кнопка **«набор: …»** в карточке профиля — переопределение для этого профиля. Пустое значение означает «как в настройках».
3. Параметр команды — переопределяет всё для одного шага.

```
text "Привет" 100
text "Привет" -1
browser find "нексус" 100
browser goto "https://example.com" speed 50
browser page +1 speed 100
```

Для браузерных команд, которые вводят URL или текст (`goto`, `page`, `set_param`, `change_param`, `set_param_url`, `change_param_url`, `find`, `search`, `tab new`, `open_in_new_tab`), можно писать `speed N` в конце. У `text` и некоторых браузерных команд последнее число тоже считается скоростью: `text "hello" 100`.

Если текст сам заканчивается числом, заключите его в кавычки: `text "hello 100"` напечатает `hello 100`, а `text hello 100` — `hello` со скоростью 100.

### Блоки, условия и подстановки

```
repeat 5 {
    browser page +1
    delay 300
}

set counter = 0
while counter < 10 {
    inc counter
    browser page +1
    delay 300
}

repeat while counter < 20 {
    inc counter
}

if counter >= 5 && browser.url contains "nexusmods.com" {
    browser copy_url
} else {
    browser search "nexus mods"
}
```

Переменные живут один запуск макроса:

```
set page = 286
set target = "https://www.nexusmods.com/games?page=" + page
browser goto "{target}"
inc page
text "текущая страница: {page}"
```

Выражения поддерживают `+ - * / %`, сравнения `< <= > >=`, `== !=`, `&& || !`, `contains`, `startsWith`, `endsWith`, `~=` и скобки. Поля `url`, `title`, `process`, `class` берутся из активного окна; не называйте так свои переменные. Также зарезервированы `date`, `time`, `clipboard` и `param:...` — это встроенные подстановки. Блоки `if` и `while` используют эти же выражения.

В тексте доступны подстановки: `{clipboard}`, `{date}`, `{time}`, `{url}`, `{title}`, `{process}`, `{param:page}` и любые переменные, например `{counter}`.

### Файлы макросов и VS Code

В окне **«Макрос…»** есть кнопки:

- **«Загрузить…»** — прочитать `.macro` или `.txt` в редактор.
- **«Сохранить как…»** — сохранить текущий скрипт в `data\macros\`.
- **«Открыть в VS Code»** — сохранить файл и открыть его в VS Code.
- **«Подсказки»** — отдельное окно со всеми командами.

Если макрос привязан к файлу, при выполнении читается актуальное содержимое файла: сохранили правку в VS Code — следующее нажатие кнопки уже использует новый текст.

Для VS Code есть расширение `tools\vscode-mouse-macros`: подсветка, автодополнение, сниппеты и проверка синтаксиса. Установка:

```powershell
powershell -ExecutionPolicy Bypass -File tools\install-vscode-extension.ps1
```

После перезапуска VS Code файлы `.macro` открываются как **MouseMackros Macro**. Подробности — в `tools\vscode-mouse-macros\README.md`.

Режимы: **однократно**, **удержание** (повтор, пока кнопка зажата), **переключение** (первое нажатие запускает, второе останавливает). Поле «Повторы» задаёт количество дополнительных проигрываний.

## Ограничения

- Игры, читающие ввод через Raw Input, могут увидеть служебные сочетания `Ctrl+Alt+Shift+…`. Обычно они безвредны; MouseMackros перехватывает их первым.
- Спец-действия MBF1000PRO (Fire Key, смена DPI и т. п.) не воспроизводятся — такая кнопка блокируется.
- Античиты могут блокировать синтетический ввод (`SendInput`). Используйте приложение там, где это разрешено правилами игры.
- Действия не попадут в окно программы, запущенной от имени администратора, если MouseMackros запущен без прав администратора.
- Фирменное ПО MBF1000PRO может перезаписывать свои профили при сохранении. Импортированный профиль не редактируйте в нём — при необходимости создайте заново.
- Приложение работает только в текущей сессии пользователя и не является службой.
- Переменные макроса живут один запуск. Цикл `while` ограничен 10 000 итераций, чтобы ошибка в условии не подвесила приложение.
- Мгновенный набор (`-1`) отправляет текст крупными пакетами; некоторые игры и защищённые поля могут принимать такой ввод хуже, чем посимвольный.

## Сборка из исходников

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download).

```powershell
git clone <репозиторий>
cd MouseMackrosSwitch
dotnet build MouseMackros.slnx
```

Готовый файл: `src\MouseMackros\bin\Debug\net10.0-windows\MouseMackros.exe`.

Публикация (зависит от установленного .NET 10 Desktop Runtime):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained false -o publish
```

Автономная сборка одним файлом (Runtime не нужен, размер больше):

```powershell
dotnet publish src\MouseMackros\MouseMackros.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

### Тесты

```powershell
dotnet run --project tests\MouseMackros.SelfTest
powershell -ExecutionPolicy Bypass -File tests\e2e.ps1
```

`SelfTest` проверяет пресеты, JSON, шаблоны, разбор клавиш, макросы, карту кнопок, чтение `.psf` (включая макросы вкладок и Copy/Paste), перенос действий в профиль и хранилище. `e2e.ps1` запускает приложение с временной папкой `--data-dir`, эмулирует `Ctrl+Alt+Shift+F12` и боковую кнопку `X1`, проверяет срабатывание действий и удаляет временные данные.
